# Web Application | Travel and Tourism
---

##### This is an Travel and Tourism Web Application, where users can search desired Places for tourism, Add them to Favourites. 
+ HTML, CSS, Javascript as Frontend Technologies.
+ Python as Backend Programming language.
+ SQlite3 | Django-Admin as Database ORM console.

### Installation
---
1. Clone the repo;
```bash
git clone https://github.com/fenny7646/Travel_and_tourism_webapp.git
cd Travel_and_tourism_webapp
```
2. Run the following commands;
```python
python install -r reqiurements.txt
python manage.py runserver
```
